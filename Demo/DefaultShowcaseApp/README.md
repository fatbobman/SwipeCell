# SwipeCell Default Showcase

This demo app is generated with Tuist.

## Open

Install Tuist, then run:

```sh
cd Demo/DefaultShowcaseApp
tuist generate
```

Open the generated workspace after generation.

## Repository Notes

Only `Project.swift`, `Sources/`, and this README are source-controlled.
Generated Xcode projects, workspaces, and `Derived/` output should not be
committed.
